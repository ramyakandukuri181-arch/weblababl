## Project Overview
This project contains three beginner-level static webpages created using HTML and CSS.

## Programs
1. portfolio.html – Personal Portfolio Website. It displays an introduction, education, skills, hobbies and contact details.
2. college.html – College Information Website. It displays college information, courses, facilities, admission details and contact information.
3. online_learning.html – Online Learning Platform. It displays available courses, benefits, goals and contact information.

## Technologies
HTML is used to structure the content. CSS is used for colors, backgrounds, fonts, spacing, borders and alignment.

## How to Run
1. Save all three HTML files in one folder.
2. Double-click any HTML file, or open it using a web browser.
3. The selected webpage will appear in the browser.

## Note
These are static demonstration webpages. The Enroll Now buttons are visual examples only and do not perform an actual enrollment. Sample email addresses and college information can be replaced with correct details.
